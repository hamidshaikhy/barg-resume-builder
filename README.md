## امکانات اصلی

- **۲۲ بخش آماده و هر تعداد بخش دلخواه:** اطلاعات شخصی (با تاریخ تولد، تأهل و نظام وظیفه)، شبکه‌ها، خلاصه، سوابق شغلی، تحصیلات، مهارت‌ها، پروژه‌ها، زبان‌ها (با چهار مهارت CEFR)، گواهینامه‌ها، دوره‌ها، مهارت‌های نرم، افتخارات، مقالات، سوابق پژوهشی، تدریس، سخنرانی‌ها، اختراعات، فعالیت داوطلبانه، عضویت‌ها، علاقه‌مندی‌ها، معرف‌ها و اطلاعات تکمیلی.
- **پیش‌نمایش زنده و ذخیره‌ی خودکار:** هر تغییر همان لحظه روی برگه دیده می‌شود و در `localStorage` همان مرورگر می‌ماند.
- **صفحه‌بندی خودکار روی A4:** محتوا بین برگه‌ها پخش می‌شود و تیتر هیچ بخشی از متنش جدا نمی‌افتد.
- **فارسیِ درست:** تاریخ شمسی یا میلادی، ارقام فارسی یا لاتین، و ایمیل و واژه‌های لاتین وسط متن فارسی سر جای خودشان؛ هم روی برگه، هم در PDF و Word.
- **رزومه‌ی انگلیسی:** با یک گزینه برگه چپ‌به‌راست می‌شود و عنوان بخش‌ها انگلیسی.
- **چیدمان با کشیدن:** جابه‌جایی بخش‌ها و موردها با موس، لمس و صفحه‌کلید؛ پنهان‌کردن هر بخشی که لازم نیست.
- **خروجی‌ها:** PDF با متن قابل انتخاب (از راه چاپ مرورگر)، PDF تصویری با دانلود مستقیم، Word (‎`.docx`‎) قابل ویرایش و فایل پشتیبان JSON که دوباره در برگ باز می‌شود.
- **چهار قلم برای برگه:** وزیرمتن، نوتو سنس، نوتو نسخ و مرکزی.
- **صفحه‌ی معرفی اسکرولی** با حالت تیره و روشن، نور دنبال موس، طرح‌های مدادی و حرکت‌هایی که همه با اسکرول جلو می‌روند؛ با «کاهش حرکت» در سیستم‌عامل، هر صحنه در حالت پایانی‌اش نشان داده می‌شود.

<a id="start"></a>

## شروع سریع

**پیش‌نیاز:** Node.js نسخه‌ی ۲۰ یا جدیدتر و npm.

```bash
git clone https://github.com/hamidshaikhy/barg-resume-builder.git
cd barg-resume-builder
npm install
npm run dev
```

برنامه را در **[http://localhost:5173](http://localhost:5173)** باز کن.

برای یک بازدید سریع:

1. صفحه‌ی معرفی را تا آخر اسکرول کن و بند لامپ بالای صفحه را بکش.
2. «ساخت رزومه» را بزن؛ رزومه‌ی نمونه باز می‌شود. متن‌ها را با حرف‌های خودت عوض کن.
3. از زبانه‌ی «قالب و ظاهر» قالب، رنگ و قلم را عوض کن.
4. از «دریافت خروجی» فایل PDF یا Word بگیر، یا یک فایل پشتیبان ذخیره کن.

### ساخت نسخه‌ی نهایی

```bash
npm run build      # بررسی نوع‌ها و ساخت نسخه‌ی نهایی در dist
npm run preview    # دیدن نسخه‌ی ساخته‌شده
```

خروجی در `dist/` قرار می‌گیرد و روی هر میزبان ایستایی کار می‌کند؛ مسیریابی هش‌محور است و تنظیم سرور لازم ندارد.

│  ├─ ResumePages.tsx   اندازه‌گیری بلوک‌ها و چیدن روی برگه‌های A4
│  ├─ resume.css        سبک قالب‌ها و قواعد چاپ
│  ├─ i18n.ts           برچسب‌های روی برگه و نام ماه‌ها

├─ store/             وضعیت برنامه و اعتبارسنجی داده‌ی ورودی
├─ pages/

│  │  ├─ scroll.ts        موتور اسکرول و وضعیت صحنه‌ها
│  │  ├─ landing.css      رنگ‌ها و همه‌ی حرکت‌های صفحه
│  │  ├─ hero.tsx …       یک فایل برای هر صحنه
│  │  ├─ sheet.tsx        برگه‌ی نمونه در پنج ظاهر
│  │  └─ doodles.tsx      طرح‌های مدادی SVG
│  └─ builder/          ویرایشگر، پنل ظاهر، پیش‌نمایش و منوی خروجی

## نکته‌های فنی

**صفحه‌ی معرفی.** موتور اسکرول در هر فریم فقط یک عدد برای هر بخش می‌نویسد: پیشرفت آن بخش از ۰ تا ۱ در متغیر CSS به نام `--p`. همه‌ی حرکت‌ها (کشیده‌شدن قالب‌ها، تایپ حرف‌ها، نخ‌ها، پرواز برگه) با `calc()` از همین عدد ساخته می‌شوند، پس React فقط در گام‌های درشت دوباره رندر می‌شود. متن تایپی فارسی حرف به حرف ظاهر می‌شود و مرورگر حرف‌ها را از روی مرز عنصرها هم به هم می‌چسباند.

**صفحه‌بندی.** رزومه به بلوک‌های کوچک شکسته می‌شود (تیتر بخش، سرِ هر مورد، هر خط توضیح). یک نسخه‌ی پنهان از کل محتوا بیرون از صفحه رسم می‌شود تا ارتفاع بلوک‌ها بدون اثر `transform` اندازه‌گیری شود؛ بعد بلوک‌ها به ترتیب روی برگه‌های ۲۱۰ × ۲۹۷ میلی‌متری چیده می‌شوند. بلوک‌هایی مثل تیتر، علامت «با بعدی بمان» دارند. در قالب‌های دوستونه هر ستون جدا صفحه‌بندی می‌شود.

**قالب‌ها.** هر ده قالب از یک ساختار HTML استفاده می‌کنند و تفاوتشان در CSS و چند تنظیم (چیدمان، نوع سربرگ، شکل موردها) است. رنگ هر قالب با چهار متغیر CSS کنترل می‌شود.

**PDF.** گزینه‌ی اول از چاپ مرورگر استفاده می‌کند (‎`@page` با اندازه‌ی A4 و حاشیه‌ی صفر) و متن واقعی می‌دهد. گزینه‌ی دوم هر برگه را عکس می‌کند؛ ظاهرش عیناً همان پیش‌نمایش است ولی متنش قابل انتخاب نیست.

**Word.** چیدمان هر قالب با پاراگراف و جدول بی‌خط بازسازی می‌شود. تکه‌های لاتینِ داخل متن فارسی در runهای جدا نوشته می‌شوند تا ترتیبشان به‌هم نریزد. قلم وزیرمتن داخل فایل جاسازی می‌شود؛ سه قلم دیگر فقط به نام ذکر می‌شوند و اگر روی سیستم نصب نباشند Word قلم جایگزین می‌گذارد. خروجی Word به قالب نزدیک است، نه یکسان با آن.

### مرزها و محدودیت‌ها

- داده‌ها فقط در `localStorage` همان مرورگر است و همگام‌سازی ابری ندارد؛ برای جابه‌جایی بین دستگاه‌ها فایل پشتیبان بگیر.
- در هر مرورگر یک رزومه نگه داشته می‌شود.
- موردی که از یک برگه‌ی کامل بلندتر باشد شکسته نمی‌شود.
- با تغییر تقویم، نام ماه‌ها عوض می‌شود ولی سال‌های نوشته‌شده خودکار تبدیل نمی‌شوند.

## English

**Barg** is a Persian, right-to-left résumé builder that runs entirely in the browser.

- Scroll-driven landing page with a dark/light theme switch (a pull-cord lamp), a cursor-following light and six pinned scenes, driven by a small CSS-variable scroll engine
- Live editor with 22 ready sections plus unlimited custom ones
- 10 formal templates with 6 colour schemes each; the sheet stays white and the text black
- Automatic A4 pagination
- Export to text-based PDF (browser print), image PDF, editable Word (`.docx`) and a JSON backup
- Jalali and Gregorian dates, Persian or Latin digits, optional left-to-right English mode
- No sign-up and no server; data stays in `localStorage`

Stack: React 19, TypeScript, Vite, Tailwind CSS 4, Zustand, dnd-kit, docx, html2canvas-pro, jsPDF.

```bash
git clone https://github.com/hamidshaikhy/barg-resume-builder.git
cd barg-resume-builder
npm install
npm run dev
```
